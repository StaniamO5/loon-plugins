# loon-plugins

自用 Loon 插件。

| 插件 | 说明 | 安装链接 |
|---|---|---|
| 哔哩哔哩去广告 | 开屏、首页横幅与信息流广告卡（视频页、评论区请配合 BiliUniverse ADBlock） | https://raw.githubusercontent.com/StaniamO5/loon-plugins/main/Bilibili/BiliSplash.plugin |
| 闲鱼去开屏广告 | 改写自家开屏接口 + 拦截广告联盟兜底开屏 | https://raw.githubusercontent.com/StaniamO5/loon-plugins/main/Xianyu/XianyuSplash.plugin |
| 虎扑去广告 | 开屏/下拉刷新广告、信息流与热榜广告卡、轮播广告位 | https://raw.githubusercontent.com/StaniamO5/loon-plugins/main/Hupu/HupuAds.plugin |
| 知乎去广告 | 开屏（Tanx/京东/SDK，改写不白屏）、下拉刷新/二楼/浮层、信息流、回答底部广告卡、横幅与弹窗 | https://raw.githubusercontent.com/StaniamO5/loon-plugins/main/Zhihu/ZhihuAds.plugin |

所有插件都需开启 MitM 并信任证书。启用后先清一次 App 缓存或杀后台重开几次，以清掉已缓存的开屏素材。
